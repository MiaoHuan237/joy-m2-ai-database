# Legacy compatibility snapshot

This directory is the smallest self-contained snapshot needed to run the 54 executable Task 3–6 regression tests while Task 8 has not migrated the pipeline into `src/joy_m2/`.

Do not add new features here and do not scan it during ordinary Codex tasks. The snapshot intentionally excludes font files, the large Task 5 input ZIP, caches, and unrelated intermediate artifacts because none is required by the regression gate.
