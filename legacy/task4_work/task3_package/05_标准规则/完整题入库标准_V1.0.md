# Joy M2 完整题入库标准 V1.0

状态：审计草案  
适用范围：微分应用45道完整题试点  
模型版本：`complete-question-v1.0-draft`

## 1. 核心原则

- 一道完整题对应一条记录，保留全部 `(a)(b)(i)(ii)` 小问。
- 不创建、抽取或调用小问级业务记录。
- 英文原题、中文题干、答案、图片、来源和校订记录相互独立且可追溯。
- 入库前逐题复核题干、公式、分值、图片和答案；发现错误必须保留原文、订正文、理由与证据。
- 缺答案题正常保留，使用 `missing_from_source`，不影响未来抽题。
- 只有Joy明确确认后，记录才可进入 `approved_for_import`。

## 2. 字段组

1. 身份来源：`question_id`、`source_id`、原题号、来源分区、文件/成员/哈希/片段哈希、页码。
2. 题目内容：完整英文题干、中文题干、LaTeX、总分、图片列表。
3. 答案：来源答案、复核答案、答案状态、复核状态、官方评分标志。
4. 分类：一个主类型、多个受控标签、Level 1–5、判级证据。
5. 校订质量：四类复核状态、校订数组、重复关系、审计备注。
6. 生命周期：审计状态、审批记录、时间戳、模型版本。

## 5. Joy Level 1–5

按整题完成所需的最高稳定认知要求评定，不取小问平均值，也不单纯按计算长度判级。

| Level | 判定标准 | 微分应用典型表现 |
|---:|---|---|
| 1 | 单一步骤、直接套用；对象和方法均明确。 | 已知切点，直接求导并写切线。 |
| 2 | 2–3个常规步骤；需一次基础判断或代入。 | 求驻点并用给定方法分类；直接相关变率。 |
| 3 | 多步骤标准DSE题；需选择方法或组织多个小问。 | 过指定点求切线；极值与拐点连续考查；基本建模变率。 |
| 4 | 需非直接建模、关键转换或多概念整合；错误路径明显。 | 未知切点且有参数；几何最优化；复杂变量关系变率。 |
| 5 | 高度综合、洞察性强或推导链长；需自主构造核心关系并验证条件。 | 限制条件复杂的最优化/变率；曲线全局分析与证明结合。 |

辅助维度为概念数、推理链、建模强度、代数负担、条件处理、易错风险，各记0–2分。总分仅供参考；每题必须写一句 `difficulty_evidence`。

## 6. 答案状态

- `source_provided`：原资料自带答案。
- `missing_from_source`：原资料没有答案。
- `web_found_verified`：联网找到并已数学复核。
- `ai_solved_verified`：独立求解并已交叉复核。
- `generated_unverified`：已生成但尚未复核，不得直接作为正式教师答案。

## 7. 自动验收规则

| 规则 | 级别 | 检查项 | 条件 |
|---|---|---|---|
| P0-COUNT-001 | P0 | 完整题总数 | 记录数必须为45。 |
| P0-COUNT-002 | P0 | 题号唯一 | question_id不得重复。 |
| P0-MODEL-001 | P0 | 完整题模型 | 不得出现父题字段、小问路径或小问后缀。 |
| P0-SOURCE-001 | P0 | 来源追溯 | source_id、文件、成员、SHA-256和片段哈希必须完整。 |
| P0-CONTENT-001 | P0 | 英文原题 | question_text_original不得为空。 |
| P0-CLASS-001 | P0 | 难度合法 | audit_passed或approved_for_import记录的Level必须为1–5。 |
| P0-CLASS-002 | P0 | 主类型合法 | audit_passed或approved_for_import记录的主类型必须在词表中。 |
| P0-CLASS-003 | P0 | 标签合法 | audit_passed或approved_for_import记录不得含非法标签。 |
| P0-ANSWER-001 | P0 | 来源答案一致 | source_provided必须有solution_original。 |
| P0-ANSWER-002 | P0 | 缺答案状态一致 | missing_from_source不得伪装为来源答案。 |
| P0-IMAGE-001 | P0 | 图片可用 | 所列图片必须存在且SHA-256一致。 |
| P0-OFFICIAL-001 | P0 | 官方答案标识 | 非HKEAA来源不得标official_marking_available=true。 |
| P0-LIFE-001 | P0 | Joy审批 | approved_for_import必须有Joy明确确认。 |
| P0-NONMUTATION-001 | P0 | 正式文件不变 | 受保护SQLite/CSV的字节数与SHA-256必须保持不变。 |
| P1-AUDIT-001 | P1 | 分类待审 | audit_pending记录允许新分类为空，但必须进入人工复核。 |
| P1-CONTENT-001 | P1 | 题答对应 | 变量、数值、分支和结论需人工复核。 |
| P1-BILINGUAL-001 | P1 | 英中一致 | 公式、数值、单位和小问结构需人工复核。 |
| P1-MARKS-001 | P1 | 分值一致 | 整题总分需与小问分值核对。 |
| P1-IMAGE-001 | P1 | 必要图片 | 几何/曲线指代需确认必要图片已关联。 |
| P1-CORRECTION-001 | P1 | 校订证据 | 订正必须保留原文、理由和证据。 |
| P2-LANGUAGE-001 | P2 | 中文表述 | 检查DSE常用书面表达。 |
| P2-PAGE-001 | P2 | 来源页码 | 页码为空时记录原因。 |
| P2-TAGS-001 | P2 | 标签数量 | 标签异常多时提示复核。 |
| P2-DUPLICATE-001 | P2 | 重复关系 | 高相似题须明确重复状态。 |

总状态：存在P0为 `FAIL`；无P0但有P1/P2为 `PASS_WITH_REVIEW`；全部清零为 `PASS`。

## 8. 本阶段边界

本文件和45题工作表只用于预检。正式SQLite/CSV、正式封包与原始MMD ZIP不得修改；完成逐题审计并取得Joy确认后，另立任务实施正式重建。
